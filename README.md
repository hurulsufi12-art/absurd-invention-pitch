# One-Sentence Absurd Invention Pitch

One sentence (129 characters) pitching a ridiculous invention for a tiny everyday annoyance: a printer that demands politeness.

> The Polite Printer refuses to print until you say please, then jams exactly once, just to remind you who really runs this office.

`main.py` (Python 3.13, stdlib only) writes that sentence to `/output/entry.txt`. Deterministic: the same text on every run.
